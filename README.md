# ARN
測驗系統
題庫撰寫方式說明
================

一、檔案放置方式

1. 題庫檔案必須與 index.html 放在同一層目錄。
2. 題庫檔名就是使用者輸入的「題庫代碼」加上 .js。

例如：

    題庫代碼：math001
    題庫檔案：math001.js

3. 管理員在「題庫公開快捷管理」輸入 math001，按下「檢查狀態」；確認檔案正常後，才可以勾選「公開於首頁列表」。
4. 公開題庫列表會逐一讀取每一個題庫檔案自己的名稱，不會把所有題庫誤顯示成同一個名稱。


二、建議使用的標準格式

每一個題庫檔案都應該建立 window.currentQuiz 物件：

    window.currentQuiz = {
        name: "電子學基礎題庫",
        time: 15,
        data: [
            {
                q: "電流的基本單位是什麼？",
                o: [
                    "(A) 安培 (A)",
                    "(B) 伏特 (V)",
                    "(C) 歐姆 (Ω)",
                    "(D) 瓦特 (W)"
                ],
                a: "A"
            }
        ]
    };

欄位說明：

name
    題庫顯示名稱。公開列表、進入測驗畫面與結果頁會使用此名稱。

time
    測驗時間，單位為分鐘。例如 time: 15 代表 15 分鐘。未設定時系統預設 20 分鐘。

data
    題目陣列。可以全部都是單選題，也可以全部都是複選題、簡答題或手寫題；不要求同一份題庫一定要混合多種題型。


三、單選題

單選題格式：

    {
        q: "下列何者是正確答案？",
        o: ["(A) 選項一", "(B) 選項二", "(C) 選項三", "(D) 選項四"],
        a: "B"
    }

注意事項：

1. o 是選項陣列，建議每個選項前面標示 (A)、(B)、(C)、(D)。
2. a 是正確答案，建議使用 "A"、"B"、"C" 或 "D"。
3. 一份題庫可以全部只放單選題，這是完整支援的使用方式。
4. 若使用 0-based 數字答案，也可以寫成 a: 1；系統會依序轉成 B。建議仍使用英文字母以提高可讀性。

完整範例：

    window.currentQuiz = {
        name: "單選題測試題庫",
        time: 10,
        data: [
            {
                q: "1 + 1 = ?",
                o: ["(A) 1", "(B) 2", "(C) 3", "(D) 4"],
                a: "B"
            },
            {
                q: "地球是什麼形狀？",
                o: ["(A) 立方體", "(B) 平面", "(C) 近似球體", "(D) 三角形"],
                a: "C"
            }
        ]
    };


四、複選題

複選題格式：

    {
        type: "multiple",
        q: "下列哪些是程式語言？",
        o: ["(A) C++", "(B) Python", "(C) HDMI", "(D) JavaScript"],
        a: ["A", "B", "D"]
    }

只有當學生選出的答案與 a 完全相同時，系統才會判定為正確。


五、簡答題

簡答題格式：

    {
        type: "short",
        q: "請寫出水的化學式。",
        answer: "H2O",
        acceptedAnswers: ["H2O", "H₂O"],
        keywords: ["H", "O"],
        score: 10,
        rubric: "答案正確得 10 分。"
    }

說明：

1. 簡答題需要在開始測驗前設定本地 AI API。
2. answer 是參考答案。
3. acceptedAnswers 可提供多個完全相等的可接受答案。
4. keywords 可設定必須出現的關鍵字；所有關鍵字都出現時可判定為符合。
5. score 是本題配分，未設定時系統通常以 10 分處理主觀題。
6. rubric 是給 AI 批改時使用的評分規則。


六、手寫計算題

手寫題格式：

    {
        type: "handwriting",
        q: "請計算：2x + 6 = 20，請寫出計算過程與答案。",
        answer: "x = 7",
        score: 10,
        rubric: "需檢查移項與除法過程；答案與過程完整得 10 分。"
    }

手寫題會顯示畫布，學生直接在畫布上書寫。送出後，系統會把手寫圖片交給設定好的 AI 進行辨識與評分。


七、舊版 bankData_* 格式

系統仍支援既有的 bankData_* 題庫格式，不需要修改既有題庫檔案：

    window.bankData_001 = {
        title: "電子學基礎題庫 (001)",
        questions: [
            {
                q: "電流的基本單位是什麼？",
                options: ["安培 (A)", "伏特 (V)", "歐姆 (Ω)", "瓦特 (W)"],
                ans: 0
            }
        ]
    };

系統會在 index.html 載入時自動將：

    title       → 題庫名稱
    questions   → 題目陣列
    options     → 選項
    ans: 0      → A
    ans: 1      → B
    ans: 2      → C
    ans: 3      → D

轉成測驗系統內部使用的格式。題庫檔案本身不會被修改。


八、命名與檢查建議

1. 題庫代碼建議只使用英文字母、數字、底線或短橫線，例如 electronics001、math_basic、test-01。
2. 題庫代碼必須與實際檔名完全一致，但不包含 .js。
3. 每題至少要有 q 或 question 欄位。
4. 選擇題必須有 o 或 options，以及 a、answer 或 ans。
5. 題庫可以只有一種題型；例如整份題庫全部都是單選題，或全部都是複選題。
6. 發布前建議先用管理員的「檢查狀態」確認題庫檔案可以載入，再公開題庫。
7. 不要在題庫檔案中放置 API Key、密碼或其他敏感資料；題庫 JavaScript 會被瀏覽器下載，內容不能視為秘密。


九、最小可用單選題題庫

以下內容可以直接另存為 only-choice.js，放到 index.html 同一層：

    window.currentQuiz = {
        name: "純單選題示範",
        time: 10,
        data: [
            {
                q: "HTML 的全名是什麼？",
                o: [
                    "(A) HyperText Markup Language",
                    "(B) HighText Machine Language",
                    "(C) Hyper Transfer Markup Link",
                    "(D) Home Tool Markup Language"
                ],
                a: "A"
            },
            {
                q: "CSS 主要用於什麼？",
                o: [
                    "(A) 管理資料庫",
                    "(B) 設計網頁樣式",
                    "(C) 發送電子郵件",
                    "(D) 編譯 C++"
                ],
                a: "B"
            }
        ]
    };

只要在管理員面板輸入 only-choice 並完成檢查，即可公開並從首頁進入測驗。


十、目前系統對題型的處理原則

單選題：直接比對一個選項。
複選題：排序後比對完整選項集合。
簡答題：使用文字比對、可接受答案或關鍵字；也可交由 AI 批改。
手寫題：使用畫布收集圖片，再交由 AI 辨識與評分。

所有題型都可以單獨形成一份題庫，不需要額外加入其他題型作為佔位題。
